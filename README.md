# HilbertSmith

A Lean 4 formalization of the OpenAI proof of the Hilbert–Smith conjecture in every finite dimension.

A second proof, written as one paper with its own Lean library (`HilbertSmithPaper`), is in progress
under `blueprint/roadmap/paper/`.
