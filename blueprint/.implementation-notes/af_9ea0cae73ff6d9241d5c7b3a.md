`HSP.forgetControl T X := HSP.forget ⋙ HSP.push Prod.snd` in diagram order (push first). Equip `X` with the trivial `C_p`-action (a type synonym or an explicit `MulAction` from `MulAction.trivial`-style instance; check the name in Mathlib, unverified). The max metric on `T × X` is Mathlib`s `Prod.pseudoMetricSpaceMax` default; `IsIsometricSMul` on the product with the action on the first factor needs a short instance. Corner and compression use the induced functor on exterior quotients, `HSP.extFunctor` (categories/supports/exterior-functor.md).
