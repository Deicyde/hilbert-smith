`HSP.tensorPerm`. The enumeration $e_n$ is `HSP.permEnum p n : ZMod p × Fin n ≃ Fin (p * n)`, defined as `finProdFinEquiv` after the identification of `ZMod p` with `Fin p` (`ZMod p` is `Fin p` by definition for `p = q + 1`); `finProdFinEquiv (c, k) = k + n * c`, which is $c\,n+k$ with $k$ zero-indexed. It is a separate one-line def so that `HSP.tauFree` (signatures/point-functors/permutation-tensor.md, for $X=C_p$) and `HSP.tauTail` reuse the same term; then `Phi ∘ tensorPerm = tauV ∘ Phi` is `rfl` on objects and entrywise on matrices. Propagation and transposes are unchanged. HS paper Section 4.
