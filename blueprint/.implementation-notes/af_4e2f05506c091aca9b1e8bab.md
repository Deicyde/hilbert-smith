**Design choices and why**
- **Inner cuts.** Each cut quotients by the side that contains the exterior and keeps the bounded side $B_m$. That side is always a grid box (or face) tensored with $P$, so [block duality](../chain-models/block-duality.md) applies directly. The outer side (a cubical shell) never needs a duality of its own. That removes HS's union lemma and the separation hypothesis. Divisibility holds for every $\alpha\in\mathbb L_4(\mathcal A_{\mathbf G}(T))$, so the choice of boundary is free, provided it is natural.
- **Cube faces instead of a ball and a hemisphere flag.** The $m$-th cut runs along the relative boundary of the face $B_m$. After $n$ cuts, $Y_n$ is two points. The source pieces are $\mathrm{Box}_{k_i}(K)$ and its iterated top faces. Support is asymptotic, so snapping to the grid of each $k_i$ costs only $\omega_\kappa(h_i)$.
- **Exact restriction.** The circle structure projects exactly to the arc structure, so the torus model restricts to each box with no error term ([box restriction](box-restriction.md)).
- **No degree theory.** $f_T\simeq\sigma_\rho\circ\text{lift}\simeq\kappa$ by explicit formulas. Only the first stage of the local-data homotopy descends to $T^n$. Hence Theorem B's hypothesis is "homotopic to $\kappa$", not "homotopic to the identity rel $\infty$".
- **Germ homotopy without rel $\infty$.** The cylinder is a block, and its labels need only uniform continuity.
