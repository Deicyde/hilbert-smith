# Sheaf categories and homotopy invariance

The invariant lives in Witt groups of sheaf categories generated by
proper direct images of constant sheaves on finite polyhedra. This
chapter defines the continuous and semialgebraic test categories,
establishes Verdier duality on exactly these categories, and proves
the cylinder relation that makes their Witt groups homotopy
invariant.

Restriction does not preserve the test categories in general (a
constant sheaf on $[0,1]$ restricts to a non-compactly-supported
sheaf on $(0,1)$), so later germ arguments take restrictions in the
ambient derived categories. Verdier reflexivity here is not stalkwise
algebraic reflexivity, which is what allows infinite-dimensional
stalks.
