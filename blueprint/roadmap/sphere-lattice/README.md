# A bounded lattice on the test sphere

Fix an odd integer $d \geq 3$. This chapter compares the continuous
theory $E_r = W_r(\T(-))$ with the semialgebraic theory
$F_r = W_r(\Pcat(-))$ on spheres, shows the rational degree-$d$
group is the line spanned by the orientation class, and bounds the
integral image inside a fixed lattice $L_d^{-1}\Z\bar u_d$. The
denominator $L_d$ depends only on $d$: it is fixed before any
action, test map, or character partition enters. Two further
properties connect the lattice to the action: degree and integral
localization away from a contractible set.
