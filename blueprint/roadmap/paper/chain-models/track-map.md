# Track maps

For $a,b,c\in\mathbb Z_p$ and $t\in[0,1]$, put $L_{a,b,c,t}=(1-t)\,\widehat a\widehat b+t\,\widehat c$ on $\mathbb R^n$. This is the identity off $\overline B(0,3/2)$, so it induces a map of $T^n$. The family $\mathcal F$ consists of all $L_{a,b,c,t}$; it contains each $\widehat a=L_{a,0,a,t}$ and $\mathrm{id}=L_{0,0,0,t}$.
