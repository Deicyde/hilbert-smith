# Mesh sequence

Let $k_0$ be the least integer $k_0\ge8$ with $3\omega(2h_0)+8h_0\le1/16$, where $h_0=4/k_0$. Set $k_i=k_0+i$ and $h_i=4/k_i$. Because $\omega$ is nondecreasing, the inequality holds for every $h_i$.
