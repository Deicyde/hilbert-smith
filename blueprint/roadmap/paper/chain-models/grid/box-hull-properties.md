# Box hull properties

Whenever the hulls below are defined (box hull hypotheses):
1. $X\subseteq Y$ implies $\mathrm{Box}_k(X)\subseteq\mathrm{Box}_k(Y)$;
2. $|\mathrm{Box}_k(X)|\subseteq N_h(X)$ coordinatewise, so $\operatorname{diam}_\infty\le\operatorname{diam}_\infty X+2h$;
3. every cube whose closed cube meets $X$ lies in $\mathrm{Box}_k(N_h(X))$.

*Proof sketch.* Each statement holds in one coordinate, and $d_\infty$ is a maximum. Closed cubes have $d_\infty$-diameter $h$.
