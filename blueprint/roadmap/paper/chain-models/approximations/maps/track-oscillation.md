# Track oscillation

For real $t$, the *track oscillation* is the set $\{d_\infty(Lx,Lx'):L\in\mathcal F,\ x,x'\in\mathbb T^n,\ d_\infty(x,x')\le t\}$, for the [track family](track-family.md) $\mathcal F$.
