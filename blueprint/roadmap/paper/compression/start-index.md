# Start index

$i_0\ge1$ is the least index such that items (1)-(3) of [buffers hold eventually](buffer-eventually.md) hold for every $i\ge i_0$. Put $\delta_i=\epsilon'_i$ for $i\ge i_0$ and $\delta_i=0$ for $i<i_0$.
