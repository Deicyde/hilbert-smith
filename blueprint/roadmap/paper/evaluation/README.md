# Evaluation of the iterated cut

A continuous labelling $c:\mathbb T^n\to S^n$ of the torus $\mathbb T^n=(\mathbb R/4\mathbb Z)^n$ turns the [chain model](../chain-models/grid/chain-model.md) $(D_i,\varphi_i)$ into a strict Poincaré complex over $S^n$, whose class in the exterior quotient is the labelled-model class $\mathfrak m_c$; homotopic labellings have equal classes. The [scalar iterated cut](../corner/theorem/scalar-iterated-cut.md) applies $n$ cut boundaries along the cube-face flag of the [cut sets](../corner/cut-sets.md), then the scalar component projection; it needs only $n$, $R$ and $s$, no control space. Each cut boundary is computed from the side away from the exterior, at the cost of a sign. For the cubical pinch $\kappa$ that side is a grid box or one of its faces tensored with $\mathbb{CP}^2$, to which the torus structure restricts exactly, so what survives is $\pm[\mathbb{CP}^2]$, whose tail signature is constant. This gives Theorem B, and its form for the test map through an explicit homotopy $f_T\simeq\kappa$.
