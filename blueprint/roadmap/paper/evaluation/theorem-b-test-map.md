# Theorem B for the test map

For fixed local data, $\sigma_{\rm tail}(\Delta_{\mathbf 1}\mathfrak m_{f_T})=[(\varepsilon,\varepsilon,\dots)]$, with $\varepsilon$ from [Theorem B](theorem-b.md). Hence, if a class $x\in\mathbb L_N(\mathcal B_{\mathbf 1,Z_0}(S^n))$ equals $\mathfrak m_{f_T}$, its iterated cut has signatures in $\{\pm1\}$ for all large $i$.

*Proof sketch.* [Test map to pinch](test-map-to-pinch.md) and [Theorem B](theorem-b.md). Then take a representative of the germ class.
