# Intrinsic interior

Let $M$ be a topological space and $n\in\mathbb{N}$. A point $x\in M$ is intrinsically interior if some open set $U\ni x$ admits a homeomorphism onto an open subset of $\mathbb{R}^n$. The intrinsic interior $M^\circ_n$ is the set of such points. The definition uses no atlas.
