# $\mathbb Z_p$ inside a compact torsion-free abelian group

Let $A\ne1$ be a compact Hausdorff commutative topological group with no element of finite order other than $1$. Then for some prime $p$ there is a continuous injective homomorphism $\phi\colon\mathbb Z_p\to A$.

*Proof sketch.* Write $\widehat A$ for the group of continuous homomorphisms $A\to\mathbb T$, the characters.
1. Characters separate points, so there is a character $\chi_0\ne1$.
2. Choose a prime $p$ and a nontrivial homomorphism from the subgroup generated by $\chi_0$ to the group $\mu_{p^\infty}\subset\mathbb T$ of $p$-power roots of unity. If $\chi_0$ has infinite order, any $p$ works and $\chi_0\mapsto e^{2\pi i/p}$. If $\chi_0$ has order $m>1$, take $p\mid m$ and the same assignment.
3. The group $\mu_{p^\infty}$ is divisible, hence an injective $\mathbb Z$-module by Baer's criterion, so the homomorphism extends to $\psi\colon\widehat A\to\mu_{p^\infty}$.
4. For $t\in\mathbb Z_p$ and $z\in\mu_{p^\infty}$, define $z^t$ through $\mathbb Z_p\to\mathbb Z/p^k\mathbb Z$ for $k$ large. By realization of characters of the dual there is a unique $\phi(t)\in A$ with $\chi(\phi(t))=\psi(\chi)^t$ for all $\chi$. Uniqueness makes $\phi$ a homomorphism.
5. Each $\chi\circ\phi$ is locally constant, so $\phi$ is continuous because characters determine the topology.
6. $\phi(1)\ne1$ because $\psi(\chi_0)\ne1$. A nonzero kernel would be some $p^j\mathbb Z_p$ by the classification of closed subgroups, which would make $\phi(1)$ an element of finite order different from $1$. So $\phi$ is injective.
