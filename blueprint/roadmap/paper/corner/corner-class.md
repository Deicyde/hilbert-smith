# The corner class

For a graph-type homotopy action on $(C,\phi)$, choose:
- a splitting $(D,\iota,r)$ of the average $E$ on $(\operatorname{Ind}C,\Phi)$, using [Average is a compatible idempotent](average-compatible-idempotent.md) and [Splitting](homotopy-idempotent-splitting.md);
- $q=(q_i)$, a scalar of propagation $0$.

Then $\mathfrak d=\operatorname{cls}(D,q^{-1}r\Phi r^*)\in\mathbb L_N(\mathcal B_{\mathbf G,Z}(T\times S^n))$.
