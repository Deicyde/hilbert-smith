# Induction

$\operatorname{Ind}:\mathcal A_{\mathbf 1}(T\times S^n)\to\mathcal A_{\mathbf G}(T\times S^n)$ sends the object $(n_i,x_i)$ to the object with the same data. Its basis at $i$ is $G_i\times\{1..n_i\}$, written $b\otimes s$, with labels $(\chi_i(s)t_b,z_b)$. A morphism $u$ goes to $u\otimes1$.
