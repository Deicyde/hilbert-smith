# The line and the transition maps

The symmetric line is a Poincaré complex over $C_{\mathbb Z}(\mathbb Q)$. Products with it carry complexes and pairs up one bounded level. This defines the transition maps and their decorated version, and the transition commutes with the localization boundary up to the line sign.
