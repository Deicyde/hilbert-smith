# Objects of the box product

Let $\mathcal B$ be a $\mathbb Q$-linear additive category with finite biproducts, $N=(M,e)$ an object of $\operatorname{Kar}\mathcal B$ and $V=(\mathbb Q^{d_n})_n$ an object of $C_\mathbb Z(\mathbb Q)$, for the category $\mathbb Q$ of [based vector spaces](../based-vector-spaces.md). The object $N\boxtimes V$ of $\operatorname{Kar}C_\mathbb Z(\mathcal B)$ has $M^{\oplus d_n}$ in position $n$ and the idempotent $e$ on each summand.

*Proof sketch.* (Proof obligation.) The diagonal map with $e$ on each summand is idempotent because $e$ is.
