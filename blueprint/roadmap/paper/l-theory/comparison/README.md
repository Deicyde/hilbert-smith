# Comparison with projective L-theory

When the lower K-groups of $\mathcal B$ vanish, the class map $L^p_k(\mathcal B)\to\mathbb L_k(\mathcal B)$ is bijective, by the half-line comparison at each stage. Lemma U, an open statement, gives this vanishing for the finite-support subcategory $\mathcal S_{\mathbf G}$ and the free categories $\mathrm{Free}(\mathbb Q[G_i])$ of the categories chapter. The coordinates of $\mathcal S_{\mathbf G}$ then detect $\mathbb L_3$, and classes in $\mathbb L_4$ have finitely many nonzero coordinates. The point comparisons and the two coordinate results rest on Lemma U. For a single free category the vanishing is classical ($\mathbb Q[G_i]$ is regular), so the comparison for $\mathrm{Free}(\mathbb Q[G_i])$ goes through Lemma U only to avoid a second route.
