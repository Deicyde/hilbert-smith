# Comparison with projective L-theory

When the lower K-groups of $\mathcal B$ vanish, the class map $L^p_k(\mathcal B)\to\mathbb L_k(\mathcal B)$ is bijective, by the half-line comparison at each level. Lemma U, an open statement, gives this vanishing for the point categories. The coordinates of the finite-support category then detect $\mathbb L_3$, and classes in $\mathbb L_4$ have finitely many nonzero coordinates.
