# The class of an object in $K_0$

Let $A$ be an additive category. An object $P$ of $\mathrm{Kar}\,A$ has a *class* $[P]\in K_0(\mathrm{Kar}\,A)$ in [$K_0$ of the idempotent completion](../k-zero.md): the image of its [isomorphism class](iso-classes.md) in the Grothendieck group.
