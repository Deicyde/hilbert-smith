# Collapse unit

For an object $X$ of $D$, $\rho(\iota_0X)=0$, so $\sigma\iota_0X$ is the one-term sum $\bigoplus_{n\in\{0\}}X$. Let $\eta_X:X\to\sigma\iota_0X$ be its structure isomorphism. Then $\eta:\mathrm{id}_D\cong\sigma\circ\iota_0$ is a natural isomorphism.

*Proof sketch.* $\rho(\iota_0X)=0$ because $(\iota_0X)_n$ is a zero object for $n\ne0$. For $f:X\to Y$, $\sigma\iota_0f$ is the $1\times1$ matrix $f$, so naturality is the naturality of the one-term biproduct inclusion.
