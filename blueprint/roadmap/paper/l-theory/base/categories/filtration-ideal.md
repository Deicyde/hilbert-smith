# Maps factoring through a subcategory

Let $\mathcal U$ be a class of objects of a [duality category](duality-category.md) $\mathcal A$. For objects $M,N$ of $\mathcal A$, let $I_{\mathcal U}(M,N)$ be the set of maps $f:M\to N$ that *factor through an object of $\mathcal U$*: $f=ba$ for some $V\in\mathcal U$, $a:M\to V$ and $b:V\to N$.
