# Completion of a duality functor

A duality functor $(F,\xi):\mathcal A\to\mathcal B$ induces $\mathrm{Kar}\,F:(M,e)\mapsto(FM,Fe)$ with $\xi_{(M,e)}=\xi_M\circ F(e^*)$. This is a duality functor, and it is strict if $F$ is.
