# Strict duality functor

A [duality functor](../duality-functor.md) $(F,\xi):\mathcal A\to\mathcal B$ between [duality categories](../duality-category.md) is *strict* if $\xi=\mathrm{id}$: for every object $M$ of $\mathcal A$, $F(M^*)=F(M)^*$, and $\xi_M$ is the identity of this object.
