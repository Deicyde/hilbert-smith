# Closed gluing

If $C_B=0$, then $(U,\Phi)$ is a strict $n$-dimensional symmetric Poincaré complex.

*Proof sketch.* [Gluing](gluing.md) with $C_B=0$: the pair map is $\Phi_\natural$, since $\mathcal C(0\to U)=U$.
