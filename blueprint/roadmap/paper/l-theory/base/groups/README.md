# Projective L-groups

$L^p_k$ is the group of cobordism classes of strict $k$-dimensional symmetric Poincaré complexes. Duality functors induce homomorphisms; unitarily isomorphic functors induce equal maps, a sum of functors induces the sum of the maps, and an equivalence induces an isomorphism. Products and finite-support sums split.
