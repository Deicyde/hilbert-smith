# Duality map of a cycle

For $\phi\in M(C)_n$ with $\partial\phi=0$, the maps $\phi_r:C_{n-r}^*\to C_r$ form a chain map $\phi_\natural:C^{n-*}\to C$. The condition $d\phi_r=(-1)^r\phi_{r-1}d^*$ is $(\partial\phi)_{r-1}=0$.
