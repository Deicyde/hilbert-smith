# Twisted sums of contractible complexes

If $X$ and $Y$ are contractible, so is $X\oplus_\tau Y$.

*Proof sketch.* Given contractions $s_X,s_Y$, set $s=\begin{pmatrix}s_X&-s_X\tau s_Y\\0&s_Y\end{pmatrix}$. The off-diagonal entry of $ds+sd-1$ is $s_X\tau(1-ds_Y-s_Yd)=0$, using $d\tau=-\tau d$.
