# Point filtration

$\mathcal S_{\mathbf G}\subset\mathcal P_{\mathbf G}$ is an involution-invariant Karoubi filtration. A morphism of $\mathcal P_{\mathbf G}$ factors through $\mathcal S_{\mathbf G}$ if and only if it is eventually zero.

*Proof sketch.* Maps to or from an object vanishing beyond $N$ factor through the orthogonal summand $M_{<N}$. These summands are filtered by $N$. An eventually zero map factors through $M_{<N}$, and a map through $\mathcal S$ vanishes beyond $N$.
