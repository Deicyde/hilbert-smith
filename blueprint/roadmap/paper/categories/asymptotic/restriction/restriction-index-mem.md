# Enumerated indices satisfy the predicate

For every $i$ and every $k\le m_i$, the [enumerated](restriction-index-embedding.md) index $e_i(k)$ satisfies $P(i,e_i(k))$.

*Proof sketch.* The enumeration takes its values in the set of indices with $P$.
