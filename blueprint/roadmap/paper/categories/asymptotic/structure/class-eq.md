# Equality of classes

In the [asymptotic category](../asymptotic-category.md), two sequences $u,v:M\to N$ have the same class, $[u]=[v]$, if and only if $u_i=v_i$ for all large $i$.

*Proof sketch.* Eventual equality is the congruence defining the quotient.
