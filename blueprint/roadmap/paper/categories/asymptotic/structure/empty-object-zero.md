# The empty sequence is a zero object

The [empty sequence](empty-object.md) is a zero object of $\mathcal A_{\mathbf G}(X)$.

*Proof sketch.* Every matrix to or from an empty basis is zero, and [every morphism is a class](class-surjective.md).
