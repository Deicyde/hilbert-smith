# The point category $\mathrm{Free}(\mathbb Q[G])$

Fix a finite group $G$. An object of $\mathrm{Free}(\mathbb Q[G])$ is a finite free $G$-set $B$. A morphism $B\to B'$ is a $G$-equivariant rational matrix $u\in\mathbb Q^{B'\times B}$, that is, $u_{gb',gb}=u_{b'b}$. Composition is matrix product. The strict duality is the identity on objects and transposes matrices. For $G=1$ we write $\mathrm{Free}(\mathbb Q)$.
