# Restriction to a subgroup

For a subgroup $H\le G$, $\mathrm{res}^G_H:\mathrm{Free}(\mathbb Q[G])\to\mathrm{Free}(\mathbb Q[H])$ sends $B$ to $B$ with the action restricted to $H$, which is still free, and sends $u$ to the same matrix. It commutes strictly with transposition, so it is a duality functor with identity $\xi$.
