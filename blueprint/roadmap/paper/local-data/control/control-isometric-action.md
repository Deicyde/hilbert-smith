# The control space is an isometric $C_p$-space

$C_p$ acts by isometries of the metric space $(T,d_T)$: the [cyclic action](control-action.md) on the control space with [the metric](control-metric-space.md) $d_T$ is isometric, because $d_T(c+s,c+t)=d_T(s,t)$ ([the cyclic action is isometric](control-action-isometric.md)).
