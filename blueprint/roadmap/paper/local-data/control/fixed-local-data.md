# Fixed local data

Fixed local data in dimension $n$, with constants $(D,\rho_+)$, consist of:
1. a local datum with constants $(D,\rho_+)$ in dimension $n$;
2. a pinch radius $\rho$ with $0<\rho<\rho_+$;
3. buffer radii $0<r<R<t<u$.

From these one reads off the test map $f$ of radius $\rho$, the control space $(T,d_T)$ with its $C_p$-action, the exterior $Z_0=\{\infty\}\cup\{z\in\mathbb R^n:|z|\ge R\}\subseteq S^n$ about the point $\sigma_\rho(0)=0$, and $Z=T\times Z_0$. None of these depends on a level $\ell$: the levels $\ell\ge1$, with $G_\ell$, $P_\ell$, $\chi_\ell$ and $r_\ell$, are chosen afterwards.
