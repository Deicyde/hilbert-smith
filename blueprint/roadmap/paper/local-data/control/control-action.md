# The cyclic action on the control space

For a local datum, let $C_p=\mathbb Z/p\mathbb Z$ and let $q_1:\mathbb Z_p\to C_p$ be reduction modulo $p$, whose kernel is $H_1$. Then $C_p$ acts on $T$ by $q_1(a)\cdot\pi(z)=\pi(a\cdot z)$. This is well defined because $\mathbb Z_p$ is abelian: if $q_1(a)=q_1(a')$ and $\pi z=\pi z'$, then $a\cdot z$ and $a'\cdot z'$ differ by an element of $H_1$.
