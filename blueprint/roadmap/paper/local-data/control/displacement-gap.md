# A uniform displacement gap

For a local datum there is $\varepsilon_T>0$ such that $d_T(t,c\cdot t)\ge\varepsilon_T$ for all $t\in T$ and all $c\ne0$ in $C_p$.

*Proof sketch.* The function $t\mapsto\min_{c\ne0}d_T(t,c\cdot t)$ is continuous, being a minimum of finitely many continuous functions, and positive because the action is free. On the compact $T$ it attains a positive minimum; if $T=\varnothing$, take $\varepsilon_T=1$.
