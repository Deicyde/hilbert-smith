# Fixed sets of the subgroups $H_j$

Let $\mathbb Z_p$ act on a set $X$ and let $j\in\mathbb N$. The fixed set of $H_j$ is $\operatorname{Fix}_j(X)=\{x\in X : a\cdot x=x \text{ for all } a\in H_j\}$.
