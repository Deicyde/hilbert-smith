# Fixed sets are closed

Let $\mathbb Z_p$ act continuously on a Hausdorff space $X$, each element acting by a continuous map. Then $\operatorname{Fix}_j(X)$ is closed for every $j$.

*Proof sketch.* $\operatorname{Fix}_j(X)=\bigcap_{a\in H_j}\{x : a\cdot x=x\}$, and each set in the intersection is the set where two continuous maps into a Hausdorff space agree.
