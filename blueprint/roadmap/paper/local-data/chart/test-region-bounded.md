# The test region is bounded

For a local datum with constants $(D,\rho_+)$, $Z^+\subseteq\overline B(0,\rho_++D)\subseteq B(0,2)$.

*Proof sketch.* For $x\in Z^+$, $|x|\le|F_0(x)|+|x-F_0(x)|\le\rho_++D$, and $\rho_++D<1/4+1/64<2$.
