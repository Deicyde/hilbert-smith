# The test regions are invariant

For a local datum, $a\cdot x\in Z^+$ for all $a\in\mathbb Z_p$ and $x\in Z^+$, and likewise $a\cdot x\in U^+$ for all $x\in U^+$.

*Proof sketch.* $F_0(a\cdot x)=F_0(x)$.
