# The test map

Given a local datum with constants $(D,\rho_+)$ and a real $\rho$ (it is used for $0<\rho<\rho_+$), define $f:S^n\to S^n$ by $f(x)=\sigma_\rho(F_0(x))$ for $x\in\Omega$, by $f(x)=\infty$ for $x\in\mathbb R^n\setminus\Omega$, and by $f(\infty)=\infty$.
