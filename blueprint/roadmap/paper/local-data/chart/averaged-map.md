# The averaged chart map

Let $\mu$ be the [Haar probability measure](../subgroups/haar-zp.md) on $\mathbb Z_p$. Given a local datum, $F_0:\Omega\to\mathbb R^n$ is
$$F_0(x)=\int_{\mathbb Z_p} a\cdot x\,d\mu(a).$$
