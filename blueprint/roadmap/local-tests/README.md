# Preparing local tests

Assume a faithful jointly continuous $\Zp$-action on a connected
$n$-manifold. This chapter finds a faithful orientation-preserving
action inside one coordinate chart, builds a degree-one test from a
compact sphere through the orbit space, and moves a positive-degree
multiple of that test into any prescribed open region of the orbit
space, using the odd-sphere homotopy calculation.

The source over $X \setminus \{b\}$ of a restricted test is an
oriented open subset of the manifold with a proper map: these are
the manifold sources used for duality later, while the compact
orbit space enters only through ordinary sheaf direct image. The
positive degree from moving a test may depend on the region.
